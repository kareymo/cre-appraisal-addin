How This Tool Works
  1. Type the property address and click Research
  2. The tool automatically gathers public data — review results in the Property Research tab
  3. Verify or select the property type if prompted
  4. Open CoStar, pull the data listed in What to Pull from CoStar, and paste it in Paste CoStar Data
  5. Click Download Workbook — your Excel file downloads automatically
  6. Open the workbook and fill in the Action Items tab — those fields flow through to the report sheets
